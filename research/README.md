# User research

Use this folder to capture the **methods, evidence, synthesis and design implications** of your real research. The brief prioritises *synthesis*, not merely raw interview transcripts.

| Subfolder/file | Add here |
| --- | --- |
| `interviews/` | Anonymised transcripts or carefully selected quotes **only if consent allows public posting** |
| `literature/` | Article notes and full bibliographic references (not copyrighted papers unless permitted) |
| `personas/` | Evidence-based personas |
| `research-findings.md` | Findings, supporting evidence, implications |

Add research dates, methods, sample information, limitations and references. Never invent participant results.
