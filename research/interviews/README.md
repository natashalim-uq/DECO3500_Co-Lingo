# Interviews

Add only data permitted to be shared publicly. Keep participants anonymised (P01, P02, etc.). Remove names, workplaces and contact details when potentially identifying.

Suggested per-interview notes:
- Date and recruitment/consent status
- Method and participant profile at a safe level of generality
- Interview objectives and prompts
- Key anonymised quotes
- Observed themes and design implications
- Limitations

Use `interview-template.md` as a starting point. Original recordings and unredacted consent forms should not be uploaded to this public repository.
